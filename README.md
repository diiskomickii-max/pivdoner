# Официальный сайт кафе стритфуда «ПивДонер» 🌯

Современный, быстрый и отзывчивый веб-сайт для заведения уличной еды **«ПивДонер»** (г. Минск, ул. Одинцова, 20).

Сайт разработан в соответствии с фирменным стилем реальной вывески заведения: сочные акцентные цвета (оранжевый и золотисто-жёлтый), глубокий графитовый фон, фактурная геометрия стритфуд-павильона и крупные аппетитные фотографии реальных блюд.

---

## 🌟 Новые современные UI-панели и возможности

1. **Интерактивная панель поиска и фильтрации меню**:
   - 🔍 **Живой поиск** по названию блюда и составу в реальном времени.
   - ✨ **Фильтр «Только с фото»** — моментально показывает позиции с реальными фотографиями блюд.
   - 📊 **Интерактивные счётчики категорий** (например, «Все блюда (14)», «Шаурма и донеры (5)», «Салаты (3)»).
   - 🔲 **Переключатель вида отображения**: Сетка (Grid) или Компактный список (List).

2. **Панель статуса в реальном времени (Live Status)**:
   - Автоматически рассчитывает текущее время и отображает индикатор: `🟢 Сейчас открыто (10:00–23:00)`.

3. **Информационная панель метрик стритфуда (Metrics Bar)**:
   - 4 стильные карточки: График 10:00–23:00, Предзаказ по звонку, Формат навынос с термоупаковкой, Локация Одинцова, 20.

4. **Интерактивные панели копирования и Toast-уведомления**:
   - Кнопки быстрого копирования телефона и адреса в 1 клик с моментальным всплывающим уведомлением («Номер скопирован в буфер!»).

5. **Мобильная плавающая док-панель (Floating Action Dock)**:
   - Удобная нижняя панель на смартфонах с быстрыми кнопками: *Меню*, *Позвонить*, *Маршрут*, *О нас*.

6. **Интерактивная аккордеон-панель FAQ (Вопрос — Ответ)**:
   - Раскрывающиеся карточки с ответами на самые частые вопросы: как сделать предзаказ, сохраняется ли тепло навынос, способы оплаты и как добраться.

7. **Адаптивность и защита от переполнения текста**:
   - Все текстовые блоки защищены правилами адаптивного переноса (`break-words`, `min-w-0`, `hyphens-auto`).
   - Исключена горизонтальная прокрутка на любых смартфонах (от iPhone SE 320px до 4K мониторов).

8. **Честный заказ без фейковых корзин**:
   - Прямой звонок по реальному номеру с вывески `+375 (44) 776 76 06` для быстрого предзаказа горячей еды навынос.

## 🛠 Технологический стек

- **React 18** + **TypeScript**
- **Vite 5** (мгновенная сборка и HMR)
- **Tailwind CSS 3** (кастомная палитра бренда, утилиты, адаптивная типографика)
- **Lucide React** (лаконичные SVG-иконки)

## 📂 Структура компонентов

```text

├── components/
│   ├── Navbar.tsx           # Шапка с живым статусом работы и кнопкой копирования

│   ├── FaqSection.tsx       # Интерактивная аккордеон-панель вопросов и ответов
│   ├── ContactsSection.tsx  # Контакты, кнопки копирования, Яндекс Карты и виджет
│   ├── OrderModal.tsx       # Модалка детального просмотра и быстрого предзаказа
│   ├── FloatingDock.tsx     # Нижняя мобильная панель быстрых действий
│   ├── Toast.tsx            # Всплывающее уведомление о копировании
│   └── Footer.tsx           # Подвал с навигацией и реквизитами
├── data/
│   └── menu.ts              # Централизованный файл данных меню, FAQ и контактов
├── App.tsx                  # Главный компонент
├── index.css                # Стили и анимации
└── main.tsx                 # Точка входа React
```

## 🚀 Запуск проекта локально

### 1. Перейдите в папку проекта:
```bash
cd C:\Users\diisk\.gemini\antigravity\scratch\pivdoner
```

### 2. Запуск в режиме разработки (Dev Server):
```bash
npm run dev
```
Сайт откроется по адресу `http://localhost:3000`.

### 3. Сборка для публикации:
```bash
npm run build
```
Файлы сформируются в папке `dist/`.
